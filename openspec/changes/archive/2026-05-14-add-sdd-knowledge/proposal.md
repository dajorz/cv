## Why

Spec-Driven Development (SDD) is an emerging methodology that complements AI-assisted engineering by formalising intent before code. Showcasing hands-on experience with SDD — and specifically with the OpenSpec and GitHub spec-kit toolchains — reinforces the CV's existing "AI-driven development" narrative and differentiates the profile from generic Copilot users.

## What Changes

- Add a new visible item in the CV listing **Spec-Driven Development (SDD)** as a known methodology, naming **OpenSpec** and **spec-kit (GitHub)** as concrete tools.
- Place it alongside the existing AI / augmented-engineering content (e.g. GitHub Copilot) so the narrative stays coherent.
- Provide the content in both languages (English and Spanish) to preserve bilingual parity.
- Update SEO metadata (`description` / `keywords`) to include SDD-related terms so the addition is discoverable.
